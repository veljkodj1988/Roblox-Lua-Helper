## 🔄 Troubleshooting

### The HUD doesn't appear after opening the file
- **Solution:** Check if your antivirus blocked it. Temporarily turn off the antivirus, run the tool, then turn it back on. Also make sure you downloaded the full file (size should be around 10 MB).

### Coordinates are showing zeros
- This happens if no character is loaded. Join a game or place an object in Roblox Studio, and the numbers will update.

### The event log is empty
- Events only show while a game is running. Open a game or playtest in Roblox Studio, and you'll see events start to fill the log.

### The HUD is too big or too small
- Use the **"Size"** buttons on the HUD (a plus and minus sign) to adjust it to your preference.
